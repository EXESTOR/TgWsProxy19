Как пользоваться

Нажмите на круг, чтобы поднять прокси на 127.0.0.1. Затем «Применить в Telegram» — ссылка откроет клиент и добавит прокси автоматически.

Если не подключается

  • Проверьте, что порт свободен (1443 любит занимать другое приложение).
  • Разрешите работу в фоне, иначе система остановит сервис.
  • Логи на вкладке «Логи» покажут причину ошибки.

О приложении

TgWsProxy19 — обёртка над консольным tg-ws-proxy (Flowseal). Python-ядро работает через Chaquopy, foreground-сервис держит WakeLock, трафик идёт через Cloudflare WebSocket.
