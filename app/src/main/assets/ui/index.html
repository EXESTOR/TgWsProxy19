Проблемы с подключением?
  • Порт 1445 по умолчанию — 1443 часто занят другим приложением.
  • Разрешите работу в фоне, иначе система остановит сервис.
  • Причину ошибки покажет вкладка «Логи».

О приложении

TgWsProxy19 — обёртка над консольным tg-ws-proxy (Flowseal). Python-ядро через Chaquopy, foreground-сервис держит WakeLock, трафик идёт через Cloudflare WebSocket.

Проект полностью создан нейросетью: код, интерфейс, отладка и сборка. Автор писал промты, придумывал фичи и тестировал всё на телефоне.
